# Frontbox Turn Based

`frontbox-turn-based` is an extension of `frontbox` that provides systems for the traditional one-player-at-a-time style of pinball (as opposed to head-to-head).

## Included Systems

### TurnBasedGame

`TurnBasedGame` implements the mechanics of a game where one player plays at a time, either individually (competitive) or on teams (cooperative).
